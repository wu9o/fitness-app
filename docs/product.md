# Movea 产品边界

## 核心用户

Movea 面向希望自己掌握运动和健康数据的个人用户，不包含会员、社交排行榜或商业订阅体系。

## 一级模块

### 今日

展示今日运动建议、最近睡眠、周目标和最近运动入口。

### 运动

支持跑步、骑行、拉伸和力量训练。户外运动记录 GPS 路线，室内训练记录时长和训练类型。

运动首页是数据中心，而不是直接进入 GPS 页面：展示本周运动次数、时长、户外距离、全部记录、训练日历、运动周报、运动状态和训练计划。点击“开始运动”后先选择运动类型，再进入对应的准备页；路线只在户外运动准备阶段按需选择。

运动结束后进入总结页，用户可标记本次体感。体感形成的主观负荷用于周报和个人趋势，必须明确标注为自我比较指标；没有设备心率或可信能量数据时不展示推测值。

健身训练进一步拆分为可复用的训练计划模板：用户可以选择动作，设置每组时长、动作间休息、循环组数、组间休息和难度；保存后可重复开始，并在执行页按动作节奏完成训练。

### 路线

提供推荐、附近和我的路线三个视图。路线可以保存、查看详情并再次跟随；进入运动页后明确显示当前跟随的计划路线。
后续增加真实 GPS 轨迹保存、偏航提醒、离线地图和路线导入。

### 健康

展示睡眠时长、睡眠质量、恢复趋势和运动相关健康数据。Apple 平台读取 HealthKit，Android 平台读取 Health Connect。

### 学习

按跑步、骑行、拉伸和力量提供知识卡片与训练教学。教学内容和运动记录解耦，方便后续扩充内容源。

### 记录

统一展示所有运动记录，支持按日期、类型和设备筛选，并能打开关联路线和健康摘要。

## Apple Watch 体验边界

Watch 端只做运动中最重要的动作：开始、暂停、继续、结束、当前时长、距离、心率和目标提示。历史分析、路线浏览和教学内容放在 iPhone/iPad/Mac 上完成。

## 数据原则

- 原始记录先写本地
- 无效 GPS 轨迹不生成路线
- 运动记录和路线记录分离
- 设备间同步采用可合并的事件/记录格式
- GitHub 备份只保存加密内容

## 当前建设重点

当前应用已经覆盖主要导航、MapLibre 地图、运动控制、训练计划、运动中心和 iOS 健康数据预览；
但这些能力的跨平台和真实设备证据仍不完整。下一步先稳定本地数据模型、GPS 回放与运动状态测试，
再完成可信户外记录、路线跟随和可复用训练计划，最后扩展 Health Connect、Apple Watch、iPad、Mac
与 GitHub 加密备份。

完整的现状边界、阶段依赖、验收标准和明确不做项见
